<b>Офлайн конвертер валют</b> — бесплатный конвертер валют с открытым исходным кодом для Android. Конвертируйте более 160 валют по последним загруженным курсам — даже без подключения к интернету.

Идеально для путешествий, покупок, международных платежей или для всех, кому нужен простой калькулятор валют без постоянного доступа в интернет.

<b>Офлайн-конвертация валют</b><br>
Загружайте курсы валют и выполняйте конвертацию прямо на устройстве. После синхронизации курсов конвертация полностью работает без интернета.

<b>Курсы валют</b><br>
Курсы предоставляются API Frankfurter на основе справочных данных Европейского центрального банка. Выбирайте, как часто синхронизировать курсы — от каждых 6 часов до еженедельно, или обновляйте их вручную.

<b>Приватность</b><br>
Конвертация валют выполняется на вашем устройстве. Доступ к сети используется только для синхронизации курсов. Аккаунт не требуется, приложение не содержит рекламы, аналитики и отслеживания.

<b>Бесплатно и с открытым исходным кодом</b><br>
Офлайн конвертер валют — свободное программное обеспечение, распространяемое по лицензии AGPLv3.
